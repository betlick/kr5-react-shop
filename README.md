## Практическая работа №21

Тема: «React: эффекты, controlled-поля формы, базовая валидация и сохранение состояния в localStorage».

Выполнено:

- создан компонент `FormField`;
- создана страница `OrderPage`;
- создан файл `src/utils/formValidation.js`;
- реализована controlled-форма заявки;
- данные формы хранятся в состоянии `formData`;
- реализован универсальный обработчик изменения полей;
- реализована базовая валидация формы;
- ошибки формы выводятся в интерфейсе;
- форма не использует `alert()` как основной способ сообщений;
- черновик формы сохраняется в `localStorage`;
- черновик формы восстанавливается при повторном открытии страницы;
- добавлена кнопка очистки черновика;
- счётчик добавленных товаров сохраняется в `localStorage`;
- использован `useEffect` для синхронизации с внешней системой браузера.

## Компоненты и файлы

- `OrderPage.jsx` — страница формы заявки.
- `FormField.jsx` — переиспользуемый компонент поля формы.
- `formValidation.js` — функция базовой валидации формы.
- `CatalogPage.jsx` — каталог и счётчик добавленных товаров.

## Примечание по useEffect

`useEffect` используется для синхронизации состояния React с внешней системой — `localStorage`. Для обычных вычислений, например расчёта ошибок формы из `formData`, используется отдельная функция, а не эффект.

## Практическая работа №22

Выполнено:

- настроены маршруты через `Routes` и `Route`;
- создана главная страница `HomePage`;
- каталог перенесён на маршрут `/catalog`;
- создана страница товара `ProductPage`;

- параметр товара получен через `useParams`;
- обработана ситуация, когда товар не найден;
- создана страница заявки `/order`;
- создана страница корзины `/cart`;
- создана страница 404 `NotFoundPage`;
- навигация реализована через `NavLink`;
- карточки товаров содержат ссылки на подробную страницу;
- обновлены стили навигации и страниц.

## Маршруты приложения

| Маршрут | Компонент | Назначение |
|---|---|---|
| `/` | `HomePage` | главная страница |
| `/catalog` | `CatalogPage` | каталог товаров |
| `/catalog/:productId` | `ProductPage` | подробная страница товара |
| `/order` | `OrderPage` | форма заявки |
| `/cart` | `CartPage` | корзина или заготовка корзины |
| `*` | `NotFoundPage` | страница 404 |

## Примечание

Для внутренней навигации используется `Link` или `NavLink`, а не обычный тег `a`. Это позволяет выполнять переходы внутри SPA без полной перезагрузки страницы.
